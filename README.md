# Fruit Shop🍎🍌
توضیح پروژه میوه‌فروشی با زبان برنامه‌نویسی پایتون 🍎🍌

معرفی پروژه:

این پروژه یک برنامه ساده برای میوه‌فروشی است که با استفاده از زبان برنامه‌نویسی پایتون طراحی شده است. هدف از ساخت این برنامه، ایجاد یک منوی ساده و تعاملی است تا مشتری بتواند از بین چند نوع میوه، میوه موردنظر خود را انتخاب کند.

نحوه عملکرد برنامه:

در ابتدای برنامه از دستور "while True" استفاده شده است. این دستور باعث می‌شود منوی میوه‌فروشی به‌صورت مداوم نمایش داده شود و مشتری بتواند چندین بار میوه انتخاب کند.

سپس با استفاده از دستور "print" نام میوه‌ها و شماره هرکدام نمایش داده می‌شود. در این برنامه چهار نوع میوه وجود دارد:

۱. Apple (سیب)
۲. Banana (موز)
۳. Orange (پرتقال)
۴. Cherry (گیلاس)

همچنین گزینه صفر برای خروج از برنامه در نظر گرفته شده است.

دریافت انتخاب مشتری:

با استفاده از دستور "input" برنامه از مشتری می‌خواهد شماره میوه موردنظر خود را وارد کند. انتخاب مشتری در متغیر "choice" ذخیره می‌شود.

بررسی انتخاب مشتری:

در این قسمت از دستورات شرطی "if" و "elif" استفاده شده است تا برنامه بتواند انتخاب مشتری را بررسی کند.

اگر مشتری عدد ۱ را وارد کند، پیام انتخاب سیب نمایش داده می‌شود.

اگر عدد ۲ را وارد کند، پیام انتخاب موز نمایش داده می‌شود.

اگر عدد ۳ را وارد کند، پیام انتخاب پرتقال نمایش داده می‌شود.

اگر عدد ۴ را وارد کند، پیام انتخاب گیلاس نمایش داده می‌شود.

خروج از برنامه:

اگر مشتری عدد صفر را وارد کند، پیام تشکر از خرید نمایش داده می‌شود و با استفاده از دستور "break" حلقه متوقف شده و برنامه به پایان می‌رسد.

انتخاب اشتباه:

اگر مشتری عددی غیر از گزینه‌های مشخص‌شده وارد کند، دستور "else" اجرا می‌شود و پیام «Invalid choice! Please try again.» نمایش داده می‌شود تا مشتری دوباره انتخاب کند.

نتیجه‌گیری:

این پروژه یک نمونه ساده و کاربردی از برنامه‌نویسی با زبان پایتون است که در آن از مفاهیمی مانند حلقه تکرار، دستورات شرطی، دریافت ورودی و نمایش خروجی استفاده شده است. با ساخت این پروژه یاد می‌گیریم چگونه یک منوی تعاملی طراحی کنیم و انتخاب‌های کاربر را با استفاده از دستورات پایتون مدیریت کنیم.

این برنامه در حال حاضر فقط امکان انتخاب میوه را دارد و می‌توان در آینده امکاناتی مانند نمایش قیمت میوه‌ها، تعداد خرید، محاسبه مبلغ کل و صدور فاکتور را نیز به آن اضافه کرد.
